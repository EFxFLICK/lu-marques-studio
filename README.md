# LU MARQUES STUDIO — demonstração de site

Site demonstrativo em React, TypeScript, Vite e Tailwind CSS, com conteúdo em português brasileiro.

## Como executar

1. Instale o Node.js 18 ou superior.
2. Abra a pasta do projeto no terminal.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra o endereço local informado pelo Vite.

Para validar a versão de produção: `npm run build` e depois `npm run preview`.

## Personalização antes de publicar

- Edite `src/config.ts` para atualizar nome, WhatsApp, Instagram, endereço e horário.
- Confirme com a proprietária os dias de funcionamento e o endereço.
- Troque as fotografias demonstrativas por imagens próprias ou imagens com licença adequada. A galeria informa que as imagens são ilustrativas.
- Substitua os depoimentos demonstrativos somente por avaliações reais, com autorização das clientes.
- Revise os textos e serviços oferecidos pelo salão.
- Configure domínio, hospedagem e política de privacidade conforme a operação real.

## Funcionalidades

- Navegação responsiva com menu móvel e cabeçalho fixo.
- Links de WhatsApp com mensagem pré-preenchida.
- Galeria com visualização ampliada e navegação.
- Carrossel de depoimentos demonstrativos.
- Formulário com validação no navegador e encaminhamento dos dados para o WhatsApp.
- Mapa incorporado do endereço informado.
- Metadados e conteúdo em pt-BR.

## Observações

O formulário não confirma horários. Ele abre o WhatsApp com os dados informados para que o salão verifique disponibilidade e responda. As imagens externas dependem de conexão com a internet. Não há backend nem armazenamento de dados neste protótipo.
